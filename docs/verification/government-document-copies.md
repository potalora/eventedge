# Verified government copies of regulatory notices

The optional `autoresearch.regulation_retrieval_policy="verified_government_copy_v1"` permits a narrowly bounded GovInfo fallback for the primary notice already discovered through Regulations.gov. It requires `autoresearch.regulation_evidence_policy="complete_document_text_v1"`. The legacy policy remains unchanged when this option is absent. The option must be fixed in the prospective configuration and carried through source capture, analysis coverage, operational reporting and immutable replay.

Only a fully captured HTTP 403, 404 or 410 response from the selected primary download can trigger the fallback. Connection failures, deadline exhaustion, over-limit bodies, malformed responses and extraction failures do not qualify. Attachments keep their exact original acquisition requirements. No source discovery is added, no API key is sent to GovInfo, and redirects are refused.

The alternate URL is derived from the recorded Federal Register document number and publication date. This version supports EPA documents catalogued as Proposed Rules, with the published action either “Proposed rule” or “Notice of availability; opportunity for public comment.” Its document header, agency, action, docket, page sequence and final publication marker must reconcile with that metadata. The catalogue title is retained separately: Regulations.gov uses a table-of-contents title that can differ from the notice heading. Alternate byte size and hash describe the acquired rendition; they never overwrite the original advertised format or size.

Extraction retains the complete preformatted notice, including ASCII tables, spacing and footnotes. Supported email-obfuscation markup is decoded deterministically with a recorded transformation inventory. Recognized subscript notation keeps the visible characters at their original columns and carries explicit subscript spans into the model request; bullet notation becomes a bullet character. Unknown markup, scripts and visual placeholders fail closed. Original response bytes remain available for replay, which reruns the same identity and extraction checks without network or model calls. The earlier refused response remains recorded even when the alternate copy succeeds.

The October 14 first-session regression adds two retained public EPA notices: Oregon document `2026-20101` omits a decorative equals separator, and Arizona document `2026-20612` includes its first page marker before the agency preamble and numeric superscript footnotes. The parser preserves these forms, records exact superscript spans, and passes their semantics into the assessment request. A first page marker must remain before the agency preamble; the complete ordered page sequence, original identity, mandatory sections and publication footer still must validate. Unsupported PDF originals and notices outside the documented EPA scope remain acquisition failures. This repair does not establish full source coverage or deployment acceptance.

The explicit `verified_government_copy_v2` option also supports the retained FDA notification-of-availability form and two FTC proposed-rule forms: receipt of a petition/request for comment, and an advance notice of proposed rulemaking/request for public comment. The new generation must freeze this option; v1 retains its EPA scope. V2 accepts a catalogue `pageCount` of zero as unknown only when the original catalogue supplies a valid page interval that reconciles with the publisher's complete ordered page sequence. It records the original declared count separately. A single-page notice uses the publisher's singular page header. Unambiguous literal URL query delimiters are preserved in link URLs and matching displayed URLs; ambiguous entities and unknown markup still fail.

FTC notices must contain their exact Regulations.gov docket in the published addresses or carry an independently captured official cross-reference. When the docket is absent, acquisition requests only the exact Federal Register document-number JSON endpoint, without credentials or redirects, under the existing deadline and source byte budget with a 2 MiB response cap. Its original receipt remains in the evidence graph. Replay reconciles the Regulations.gov document ID, docket and agency, Federal Register document number, publication date, page interval, CFR part and printed RIN. A printed different docket cannot be replaced by this cross-reference. The FTC's Matter/File numbers are never treated as Regulations.gov docket IDs. Missing, malformed, unavailable or oversized metadata leaves acquisition incomplete.

The retained source refusal tests preserve four remaining limitations. SEC documents `2026-20474`, `2026-20466` and `2026-20360` have GovInfo HTML renditions with omitted graphics; no supported complete asset/PDF contract certifies them. The PDF-only EPA document `EPA-R08-OAR-2023-0495-0075` returned HTTP 403 and lacks a Federal Register number in its original catalogue metadata. A similar official notice found by title/date/docket does not establish that it is the same submitted file. These documents remain failures; this version supplies neither a guessed alternate nor a text-only exemption. Public-fixture acquisition/replay success for other notices does not prove a complete live source run or native model acceptance.

Discovery, metadata, failed response bodies and alternate bodies all consume the existing Regulations source byte budget and inherited deadline. Acquisition completeness, supported analysis coverage and operational acceptance remain separate. A successful copy fetch or passing local tests do not establish completion of the sixteen-book native run.
