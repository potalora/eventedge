# Verified government copies of regulatory notices

The optional `autoresearch.regulation_retrieval_policy="verified_government_copy_v1"` permits a narrowly bounded GovInfo fallback for the primary notice already discovered through Regulations.gov. It requires `autoresearch.regulation_evidence_policy="complete_document_text_v1"`. The legacy policy remains unchanged when this option is absent. The option must be fixed in the prospective configuration and carried through source capture, analysis coverage, operational reporting and immutable replay.

Only a fully captured HTTP 403, 404 or 410 response from the selected primary download can trigger the fallback. Connection failures, deadline exhaustion, over-limit bodies, malformed responses and extraction failures do not qualify. Attachments keep their exact original acquisition requirements. No source discovery is added, no API key is sent to GovInfo, and redirects are refused.

The alternate URL is derived from the recorded Federal Register document number and publication date. This version supports EPA documents catalogued as Proposed Rules, with the published action either “Proposed rule” or “Notice of availability; opportunity for public comment.” Its document header, agency, action, docket, page sequence and final publication marker must reconcile with that metadata. The catalogue title is retained separately: Regulations.gov uses a table-of-contents title that can differ from the notice heading. Alternate byte size and hash describe the acquired rendition; they never overwrite the original advertised format or size.

Extraction retains the complete preformatted notice, including ASCII tables, spacing and footnotes. Supported email-obfuscation markup is decoded deterministically with a recorded transformation inventory. Recognized subscript notation keeps the visible characters at their original columns and carries explicit subscript spans into the model request; bullet notation becomes a bullet character. Unknown markup, scripts and visual placeholders fail closed. Original response bytes remain available for replay, which reruns the same identity and extraction checks without network or model calls. The earlier refused response remains recorded even when the alternate copy succeeds.

Discovery, metadata, failed response bodies and alternate bodies all consume the existing Regulations source byte budget and inherited deadline. Acquisition completeness, supported analysis coverage and operational acceptance remain separate. A successful copy fetch or passing local tests do not establish completion of the sixteen-book native run.
