# Bounded resilience acceptance

This checkpoint closes the reduced-profile engineering milestone when the focused CFTC repair checks and topic-branch CI pass. It does not require every live provider to be healthy at once. Production deployment and a complete accepted live sixteen-book research/replay run remain separate decisions and evidence.

The profile remains `configs/research-without-bulk-filings.json`: all EDGAR research is disabled and dependency isolation is enabled. The retired bulk-filing campaign is not resumed.

The CFTC transport has finite per-archive bounds of 16 MiB compressed response and 64 MiB for the selected uncompressed report. It reads the exact expected member in memory and writes no extracted archive files. These bounds replace an unbounded SDK download/extraction path; they do not raise the existing source-phase or model budgets. Source adapters without an exposed timeout remain cooperative inside the existing bounded outer source worker; this checkpoint does not claim every SDK has its own hard per-call deadline.
