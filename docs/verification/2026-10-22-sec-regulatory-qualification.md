# SEC and regulatory qualification acceptance

This follow-up repairs the standard CI environment's Anthropic incompatibility
and implements bounded evidence qualification for SEC ownership filings and
the demonstrated regulatory-document gaps. It does not enable excluded
strategies, change an experiment generation, or deploy code.

The parent source-reliability branch constrains Anthropic to its supported 1.x
API generation. The same authentication and request-identity tests that failed
with 2.1.0 pass with the locked 1.11.0, existing 1.15.0, and freshly resolved
1.17.0. See [the compatibility evidence](2026-10-22-anthropic-sdk-compatibility.md).

The new Form 4 policy retains complete ownership XML context and admits only
explicitly reviewed issuer/security bindings. Original filings, amendments,
joint reporters, footnotes, plan disclosures, derivative context and unsupported
capabilities remain distinguishable. A bounded native Apple window retained
both discovered originals and prepared one journal-only request for five
admitted stock sales. Independent replay in a network-disabled namespace
reproduced the capture exactly. See [the Form 4 qualification](2026-10-22-sec-form4-qualification.md).

CFPB v4 retrieval recognizes the actual mortgage-credit request for information,
including its two CFR parts, exact authority/action and complete official body.
The final native adapter check used four requests, recovered the complete text
after the native download's 403, and replayed request preparation with networking
blocked. See [the CFPB result](2026-10-22-cfpb-v4-qualification.md).

Linked regulatory publications retain original/correction dependencies and
historical repost identities separately. Their availability comes from the

requires the explicit prospective paper-research configuration; accepted-source

[the policy contract](2026-10-22-linked-publication-policy-integration.md).

## Remaining qualification boundaries

The Form 4 result covers a declared issuer/window and reviewed security binding.
It does not resolve amendment chains or joint-owner allocation, establish
exchange execution from purchase/sale codes, or demonstrate model quality.
Structural-only annual/material-event HTML remains barred from complete-filing
model assessment; selected-page research has a separate scope.

Source-complete SEC regulatory originals with graphics still require actual
image interpretation and independent image review before final semantic
assessment. Preparing recognition requests is not evidence that those steps
ran. A complete publication also does not establish applicability to a traded
issuer. No authenticated model calls were used for this qualification.

Congress remains display/audit-only. Futures curves and state-event strategies
remain deferred. No production checkout, generation worktree, manifest, state,
service or timer was changed. The changes require PR review and a separately
authorized new generation before deployment.
