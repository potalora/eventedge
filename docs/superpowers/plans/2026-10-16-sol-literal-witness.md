## Design

Introduce Sol plan V6/request V12. Preserve exact historical V3/V9, V4/V10 and V5/V11 construction and replay. V12 recognition uses the exact V11 recognition instructions. V12 review receives the current candidate structure and descriptive prose, with all direct literal fields replaced by a uniform placeholder, including null matrix slots and nullable anchor markers. A deterministic host-generated ordered slot inventory identifies every withheld field and its source image. The review must return one source-read string or null per slot, alongside every existing whole-original, structural, association and omission check. Runtime compares each decoded string/null exactly against recognition before accepting. No punctuation, whitespace, Unicode, spelling, linebreak or blank normalization is permitted.

The slot inventory covers standalone text; every physical matrix cell; unit quotes; note markers and bodies; all anchor marker_text fields; foreign header/continuation quotes; and foreign consumer quotes and marker_text. Image ownership follows the actual literal: local text/matrix/units/anchors belong to image1, note body/marker to its note image, foreign quotes to their declared context image. Keep source metadata, structure, typed links, descriptions and associations available for review. All original PNG bytes and order remain unchanged.

This is partial withholding, not complete blindness or statistical independence. Descriptions and association prose can repeat literals; retaining them is necessary to review their meaning. Two Sol reads can also share an error. Acceptance therefore still requires an actual fresh native test and independent comparison against original images. The change makes disagreement mechanically decisive; agreement alone is not a source-fidelity proof.

Witness shape/type failures are malformed review; a well-formed witness mismatch is rejected review even when all checks are true. Host feedback supplies field paths and generic mismatch reasons, not the witness's proposed source answer. Preserve the existing one-correction state machine: two calls normally, at most four actual calls, review-only retry for malformed review, fresh recognition after rejected review. Corrected review receives no prior witness, candidate-specific feedback or prior literals beyond any descriptive prose in its current candidate. Keep Sol/high, subscription transport, 4096 logical token setting, 240-second calls, 9000-second phase, worker limits and every admission/coverage gate unchanged.

Meaningful regressions must demonstrate exact mismatch rejection despite all-positive masks, full slot coverage including foreign literals/null cells, untouched historical requests/replay, request tamper rejection, correction/reuse/failure replay, and unchanged transport/model routing. Test punctuation, linebreaks, Unicode symbols/markers, omitted/reordered/wrong-length witnesses and false omission/geometry checks despite matching witnesses. Exercise representative complex content, not just the known note.

After independent code review and local checks, seal a fresh exact candidate and run one finite table001 native target with original images and no injected answer. Only a successful actual source comparison permits the remaining four already-defined probes. Every newer release candidate needs its own passing exact CI. No deployment until complete native and release gates pass; preserve all prior evidence and failed-generation state.
